# Windows Server 2022 – Active Directory Administration 🖥️

## 📌 About This Project

This repository contains a practical assignment completed as part of my **Network Computer Systems Administration (ASIR)** studies.

The main objective was to learn how to install, configure and administer a Windows Server environment using Active Directory, while practising common systems administration tasks.

The project was completed in a virtualized environment using Oracle VirtualBox.

## 🛠️ Technologies & Tools

- **Windows Server 2022** – Server installation and administration.
- **Active Directory Domain Services (AD DS)** – Domain, user and group management.
- **DNS** – Domain name resolution and configuration.
- **Group Policy (GPO)** – Configuration of policies and restrictions.
- **PowerShell** – Basic administrative commands.
- **Oracle VirtualBox** – Virtual machine management.
- **Windows Client** – Domain connectivity and configuration testing.

## ⚙️ What I Did

During this practice, I worked on the following tasks:

- Installed and configured a Windows Server virtual machine.
- Configured network settings and domain services.
- Created and managed organizational units (OUs), users and security groups.
- Practised Active Directory administration using PowerShell commands.
- Configured Group Policy Objects (GPOs).
- Worked with shared resources and access permissions.
- Connected a Windows client to the domain.
- Tested configurations and troubleshot errors encountered during the exercises.
